Welcome to Spring Boot Application

This application demonstrates migration from Struts 1.0 to Spring Boot

Migration Highlights

  • Struts Action → Spring MVC Controller: Action classes are replaced with @Controller annotated classes
  • struts-config.xml → Annotations: XML configuration replaced with Java annotations like @RequestMapping
  • ActionForm → Model/Entity: ActionForm beans replaced with JPA entities and DTOs
  • JSP → Thymeleaf: JSP templates replaced with modern Thymeleaf templates
  • DAO Pattern → Spring Data JPA: Manual DAO implementation replaced with Spring Data repositories
